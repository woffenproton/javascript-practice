# JavaScript Practice
A collection of small JavaScript exercises for learning fundamentals.
## Files
| File | Description |
|------|-------------|
| `basics.js` | Variables, types, and operators with console.log examples |
| `arrays.js` | Map, filter, and reduce array methods examples |
| `functions.js` | Default parameters, arrow functions, and closure counter |
## Run
```bash
node basics.js
node arrays.js
node functions.js
```
